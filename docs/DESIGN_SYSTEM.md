# Design System

Not started yet — this belongs to Phase 9 (Design Lab) and Phase 10 (Design
Blueprint). Placeholder so the doc exists and gets filled in as real
decisions are made, rather than designed speculatively now.

## Interface direction (already decided, applies from the first screen)

- Premium, clean, minimalist, Apple-inspired, professional, fast, easy to
  understand.
- Avoid: generic "AI dashboard" look, excess cards, random gradients, icon
  overload, color overload, information overload, unnecessary animation.
- Prioritize: typography, spacing, hierarchy, clarity, states, consistency.
