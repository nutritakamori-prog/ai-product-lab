# Memory

**Responsibility:** two compact memories, never sent to agents in full.
Product Memory: users, objectives, processes, decisions, recurring problems,
opportunities, risks, rules. Design Memory: principles, decisions, components,
tokens, patterns, known mistakes, approved pages. The Context Engine pulls only
the relevant slice for a given task — this module is what makes that slice exist.

**Not this module's job:** deciding what's "relevant" for a specific run
(that selection logic lives in `core/context`).
